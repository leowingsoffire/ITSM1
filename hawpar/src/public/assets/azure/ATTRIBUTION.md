# Azure service icon attribution

The SVG files in this folder are the **official Microsoft Azure architecture icons**.

| | |
| --- | --- |
| Publisher | Microsoft Corporation |
| Official source | <https://learn.microsoft.com/azure/architecture/icons/> |
| Obtained via | <https://github.com/loryanstrant/MicrosoftCloudLogos> (community mirror) |
| Modifications | None — files are byte-for-byte as published, only renamed for readability |

## Terms of use

Microsoft permits these icons to be used to reference Azure services in
architecture diagrams, training materials and documentation, subject to the
[Microsoft Trademark and Brand Guidelines](https://www.microsoft.com/legal/intellectualproperty/trademarks).
They **must not** be altered, recoloured, or used to imply Microsoft endorsement
of this application.

In this prototype they appear only in the **Solution Blueprint** architecture
diagram and the **Cost & Value** breakdown, purely to identify which Azure
service each component or line item maps to.

All logos remain the property of Microsoft Corporation. Haw Par Corporation and
this prototype claim no ownership of them.
